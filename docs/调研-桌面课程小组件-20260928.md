# 调研：桌面课程小组件该有什么功能（2026-09-28）

> 本轮用户反馈：功能太少、要浅色、课程默认收起按状态显示、调研要看得见。
> 本文是调研结论落盘，不是事后文档。所有来源均实际抓取（gh api）。

## 一、参考对象

### 1. Class Widgets 1（Class-Widgets/Class-Widgets，★767）
README 特性清单（原文摘录）：
- 将今日的课程安排以**小组件**的样式呈现
- **上下课提醒 + 预备铃**，支持 TTS
- 主题系统、亮/暗色主题、跟随系统
- 课程表编辑界面；多课程表管理；CSES 通用格式导入导出
- 调休、换课应对方案
- "天气"、"自定义倒计时"等附加小组件

### 2. Class Widgets 2（RinLit-233-shiroko/Class-Widgets-2，★194）
"课程表的终极形态"，PySide6 + RinUI 重写。架构启示（v1→v2 重写理由）：
分层组件、插件化。对我们有效的点：**v1 的核心卖点是"小组件呈现 + 上下课提醒"**，
其它（天气/插件广场）是长尾。

### 3. cc-switch（farion1231/cc-switch）——视觉基准
浅色 tokens（src/index.css 原文，HSL）：

| token | 值 | 换算 |
|---|---|---|
| background/card | `0 0% 100%` | #FFFFFF |
| foreground | `240 10% 3.9%` | #0A0A0B |
| secondary / muted | `240 4.8% 95.9%` | #F4F4F5 |
| muted-foreground | `240 3.8% 46.1%` | #6E6E76 |
| primary | `210 100% 56%` | **#1F8FFF** |
| border | `240 5.9% 90%` | #E4E4E7 |
| destructive | `0 84.2% 60.2%` | #EF4444 |
| radius | 0.5rem | 8px |

深色只是它的 `.dark` 覆盖——**默认就是浅色白卡**。上一轮抄了深色分支，方向错了。

### 4. WakeUp 课程表 / 小爱课程表（Android 双雄，公认交互范式）
- 默认**周视图网格**（列=星期，行=节次），今天列高亮
- 周末无课时自动收起列
- 周次切换（‹ 第 N 周 ›）
- 点课程看详情；今天视图只列今天的课 + 状态

## 二、功能矩阵：它们有 → 我们做不做

| 功能 | ClassWidgets | WakeUp | 本轮决策 | 理由 |
|---|---|---|---|---|
| 今日课程 + 当前节状态 | ✓ | ✓ | **做（已有，重做交互）** | 核心 |
| 课程按状态收起（未开始/进行中/已结束） | 部分 | ✓ | **做** | 用户点名 |
| 点课程展开详情（地点/老师/周次） | ✓ | ✓ | **做** | 用户点名"课可以展开" |
| 周视图网格 + 周次切换 | ✓ | ✓ | **做** | 课表页；WakeUp 范式，全学期缓存已在手 |
| **预备铃（上课前 N 分钟提醒）** | ✓（明星功能） | — | **做** | 不用打开学习通就知道要上课；60s 本地定时器，纯缓存零网络 |
| 下课提醒 | ✓ | — | 不做单独提醒 | 当前节进度条+倒计时已覆盖，避免轰炸 |
| 作业 DDL 倒计时看板 | — | — | **做** | 我们独有优势：学习通直连；ClassWidgets 没有作业概念 |
| 新动态时间线 | — | — | **做（已有）** | 我们独有 |
| 天气 | ✓ | — | 不做 | 偏离"学习通助手"定位，需要额外数据源 |
| TTS 播报 | ✓ | — | 不做 | 打扰场景（教室/图书馆）多，Toast 够用 |
| 调休/换课手动编辑 | ✓ | ✓ | 不做 | 学习通课表是权威源，本地改了反而对不上 |
| 插件系统 | ✓ | — | 不做 | 自用产品，YAGNI |

## 三、本轮定稿的信息架构

```
迷你条(340×64)：状态点 + 当前课/下一节 + 倒计时 + 进度条     [点击展开]
展开卡(~340×520)：顶部标签页 今天 / 课表 / 作业 / 动态
  今天：日期周次 + 今日概览(N节课·已完M) + 课程行(状态chip，点开看详情) + 最近DDL
  课表：‹ 第N周 › + 周网格(节次×星期，今天列高亮，课程色哈希)
  作业：DDL 列表(紧迫度色条 + 剩余时间chip)，点击开详情窗
  动态：时间线(彩点 + 课程 + 标题 + 时间)
顶栏常驻：同步按钮(扫描时旋转) + 未读角标(点击跳动态页) + 右键菜单
```

色彩纪律（cc-switch 浅色）：白卡 + #E4E4E7 边框分层，主色 #1F8FFF 只出现在
当前项/交互态/品牌点；课程色仅用于周网格课程块（哈希到 6 个淡彩底色）。
